# 流動

GitHub Pages 前端畫面。資料同步仍使用 Google Apps Script 和 Google 試算表。

部署網址預計為：

https://dearbonnie.github.io/liudong-app/

## 上傳到 GitHub

把這個資料夾內的檔案上傳到 `dearbonnie/liudong-app` repository。

需要的檔案：

- `index.html`
- `manifest.webmanifest`
- `icon.png`

## Apps Script 後端

GitHub Pages 版本需要把 `Code_GITHUB_BACKEND.gs` 貼到 Apps Script 並重新部署。
